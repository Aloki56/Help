# SIGNATURE FRAME SYSTEM
### إطار إعلامي تراكبي (Overlay) بدقة 1080×1920 — بنسبة 9:16 — بشفافية Alpha حقيقية

ملف `output/SignatureFrame_1080x1920.png` هو **الأصل البصري** المطلوب: طبقة شفافة تُضاف فوق أي صورة أو فيديو،
تحتوي على **الإطار الهندسي + الشعار الأصلي فقط** — بلا نصوص، بلا عناوين، بلا أيقونات، بلا تواريخ، بلا علامات مائية.

## 2. مفهوم التصميم

**الفكرة:** «نافذة الحدث» — الإطار لا يؤطّر الصورة ليحجبها، بل ليحدّد مساحة الحدث ويتركها سليمة.

* **وحدة الهوية المتكررة (Signature Notch):** شريط أحمر قصير بنهايات مائلة بزاوية 45°.
  هو العنصر الصغير الذي يتكرر في الإطار ويمكن أن يصبح بصمة الصفحة (في الصور المصغّرة، الفواصل، المقدمة…).
* **القطع المائل 45° / وحدة 28px:** يتكرر في الزوايا الأربع وفي حاضنة الشعار، ما يربط كل العناصر بنظام هندسي واحد.
* **انقطاعات محسوبة:** لا يوجد مستطيل مغلق؛ كل حافة مقسّمة بمقاطع ذات إيقاع مدروس
  (أعلى: 132 / 54 / 140 / 62 / 176 / 62 / 140 / 54 / 132) — التكرار المنتظم يمنح الإحساس المؤسسي،
  والانقطاع يمنع الإطار من أن يتحول إلى قفص حول المشهد.
* **حاضنة الشعار:** لوحة هندسية شفافة جزئيًا (≈69%) تقيس نفسها تلقائيًا على مقاس الشعار،
  بقطع مائل يسارًا وشريط أحمر على حافة البداية (يمين — اتجاه القراءة العربية).
  حافتها اليمنى على المحور نفسه (x = 1016) مع خط الإطار الأيمن: أي أن الشعار **جزء من بنية الإطار** لا صورة ملصقة فوقه،
  والانقطاع بينهما (y 122 → 214) محسوب ليمرّ منه زر البحث في TikTok.
* **التباين:** كل خط مرسوم فوق هالة داكنة بسماكة 1px، ليبقى الإطار مقروءًا فوق الثلج الأبيض كما فوق الليل الداكن.

## 3. الحفاظ على المحتوى وواجهة TikTok

| منطقة واجهة TikTok | عناصر الإطار فيها |
|---|---|
| التبويبات العلوية (منتصف y 118–205) | **لا شيء** (الحافة العلوية نُزّلت إلى y = 214) |
| زر البحث (أعلى اليمين) | **لا شيء** (حاضنة الشعار تنتهي عند y = 122) |
| شريط الأزرار الأيمن (y 470–1130) | **لا شيء** (الحافة اليمنى تكتفي بالزاويتين فوقه وتحته) |
| القرص الموسيقي (أسفل اليمين) | **لا شيء** (الحافة السفلية عند y = 1400 = 73% من الارتفاع) |
| الوصف واسم الحساب (أسفل اليسار) | **لا شيء** |
| شريط التنقل السفلي | **لا شيء** |

نسبة الحبر في التصميم كله: **≈2.25% من مساحة الإطار**، والمنطقة الوسطى (التي يظهر فيها المحتوى) شفافة بنسبة 100%.

## 4. الشعار

* مستخدم كما هو: نفس الحروف، نفس النسب، نفس الألوان — بلا إعادة رسم ولا تعديل ولا تشويه.
* يوضع داخل حاضنته بعد قصّه على حدوده الحقيقية وتصغيره بالحفاظ التام على نسبة العرض إلى الارتفاع.
* لو كانت نسخة الشعار بلا شفافية (JPG)، يزيل السكربت الخلفية البيضاء المحيطة فقط.
* **لم تُكتب أي كلمة أو حرف أو رمز غير موجود أصلًا داخل الشعار.**

## 5. التحقق من الشفافية (أداتان مستقلتان)

```
ImageMagick:  Type: TrueColorAlpha — alpha: 8-bit — Alpha: none #00000000
Python/PIL :  mode RGBA — center pixel (0,0,0,0) — interior max alpha = 0
```
المنطقة الداخلية `x 220–860 / y 260–1340` بحد أقصى للشفافية = **0** (أي شفافة تمامًا).

## 6. إعادة التوليد

```bash
python3 -m venv .venv && .venv/bin/pip install Pillow numpy
.venv/bin/python build_frame.py --logo assets/logo.png --outdir output
.venv/bin/python make_preview.py --frame output/SignatureFrame_1080x1920.png --outdir preview
```

## 7. طريقة الاستخدام في TikTok

1. افتح TikTok ← إنشاء ← ارفع الفيديو أو الصورة.
2. من أدوات التحرير اختر **Overlay / التراكب** ← أضف `SignatureFrame_1080x1920.png`.
3. وسّع التراكب ليغطي الإطار كاملًا ثم أرسله إلى الخلف فوق المحتوى.
4. إن أردت مساحة أكبر للمحتوى استخدم نسخة `_topzone`.
5. لا حاجة لأي تعديل يومي: الإطار ثابت، استخدمه كما هو في كل منشور.
